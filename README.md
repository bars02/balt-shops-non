# منصة نون | NOON Multi-Store Women's Fashion Platform

منصة أزياء نسائية راقية متعددة المتاجر (Multi-Store / Multi-Tenant)، تجمع نخبة دور الأزياء والعبايات تحت سقف رقمي موحد مع لوحة تحكم إدارية مركزية.

---

## 🌟 مميزات المنصة

- **متاجر مستقلة متكاملة**:
  - **إليجانس نون (Elegance NOON)**: أزياء السهرة والفساتين المخملية والمطرزة.
  - **رويال نون (Royal NOON)**: عبايات ملكية وبشوت مطرزة بالزري الأصيل.
  - **كاجوال نون (Casual NOON)**: أطقم اللِنين الحريرية والملابس العصرية اليومية.
- **عارض الستوريات والقصص (Stories Engine)**: نظام ستوريات متكامل مدمج في شعار المنصة لعرض أحدث الكولكشنات مع إمكانية التوجيه المباشر للمتجر.
- **لعبة اليوم (Daily Slot Machine)**: آلة حظ تفاعلية تمنح العميلات جوائز وقسائم خصم يومية مع إمكانية نسخ الكود.
- **حركة موشن فاخرة (GSAP Motion)**: واجهة ترحيبية بانسيابية عالية مع شريط تقدم متناسق.
- **طلب مباشر عبر واتساب**: توجيه الطلبات مع تفاصيل المقاس والكمية مباشرة لواتساب المتجر المختار.
- **لوحة إدارة مركزية (`mb-dashboard/`)**:
  - إدارة المتاجر وأقسامها.
  - إدارة المنتجات والمقاسات والأسعار.
  - نشر وإدارة ستوريات وقصص المنصة.
  - إعدادات لعبة الحظ والجوائز.
  - مراجعة تقييمات وآراء العميلات.
  - مصادقة محمية ومشفرة عبر Supabase Auth.

---

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend**: HTML5, Vanilla JavaScript (ES Modules), TailwindCSS, GSAP Animation.
- **Backend & Cloud DB**: Supabase (PostgreSQL, Row Level Security, Auth).
- **Architecture**: طبقة بيانات موحدة (`db.js`) مع نظام حماية مرن وحفظ محلي احتياطي (`LocalStorage Fallback`).

---

## ⚙️ إعداد المشروع وتشغيله

1. انسخ ملف الإعدادات:
   ```bash
   cp config.example.js config.js
   ```
2. ضع مفاتيح Supabase الخاصة بك في `config.js`.
3. قم بتنفيذ استعلامات قاعدة البيانات الموجودة في [supabase-schema.sql](supabase-schema.sql) داخل Supabase SQL Editor.
4. شغّل المشروع عبر أي خادم محلي (مثل Live Server في VS Code).
